# Spiekbrief Git en GitHub

## 1. Clone, commit, push en pull
clone: kopie van GitHub -> naar je computer (1 keer, aan het begin)
commit: je wijzigingen bewaren met een berichtje, alleen op je eigen computer
push: je commits van je computer -> naar GitHub sturen
pull: nieuwe dingen van GitHub -> naar je computer halen
## 2. Een goed commitbericht
Goed voorbeeld: 'Spiekbrief: uitleg over gitignore toegevoegd'
Slecht voorbeeld: 'aanpassingen'
Het goede bericht zegt in 1 regel wat er precies veranderde, zodat je later in de History meteen ziet welke commit je zoekt. Bij "aanpassingen" weet niemand wat er gewijzigd is.
## 3. Gitignore
In .gitignore staan bestanden die Git moet negeren, zoals systeembestanden en zip- of logbestanden, zodat ze nooit per ongeluk in de repository terechtkomen.
